# Индустриальный переход

Переход между страницами показывает художественную индустриальную сцену. Площадка, две градирни и два крана образуют вымышленную композицию. Документальная фотосъёмка объектов ROIN WORLD указана отдельно в [реестре фотографий](../../docs/media.md).

## Источники изображения

Для этой версии средствами OpenAI ImageGen подготовлены три исходных изображения. Широкий и вертикальный кадры сохраняют общий свет и композицию. Портретная версия позволяет показать обе башни на узком экране. Файлы в этом каталоге предназначены для повторного монтажа; браузер загружает оптимизированные копии из `public/transition/`.

| Исходник | Содержимое |
| --- | --- |
| `wide-master.png` | Общий план вымышленной промышленной площадки в сумерках. |
| `portrait-master.png` | Самостоятельная вертикальная композиция той же сцены. |
| `cloud-master.png` | Объёмный облачный вал с альфа-каналом. |
| `foreground-master.webp` | Отдельно сгенерированная правая гряда с боковым тёплым светом. Альфа-канал и цвет сохранены без потерь в оригинале. |

Файлы `towers.svg` и `cranes.svg` — векторные эскизы прежней версии. Текущая сцена использует растровые материалы.

## Ахроматический мастер для сайта

Шесть слоёв имеют отдельные широкие и мобильные версии. Для публикации тон заново рассчитан из цветных монтажных оригиналов, а геометрия масок совмещена с исходными проходами. Углисто-серое небо отделяет светлые шлейфы от силуэтов башен, металлические фермы остаются видны сквозь средний туман. Полутона и прозрачность записаны в WebP. Геометрия, паузы и переход к следующей странице управляются компонентом.

| Слой | Широкая версия, байт | Вертикальная версия, байт |
| --- | ---: | ---: |
| Площадка и башни | 61 546 | 36 932 |
| Фермы кранов | 38 028 | 16 956 |
| Пар над башнями | 4 322 | 3 054 |
| Ближний левый туман | 41 258 | 30 760 |
| Средний туман | 20 638 | 12 402 |
| Ближняя правая гряда | 62 242 | 16 944 |
| **Всего** | **228 034** | **117 048** |

Мобильные файлы выбираются на портретном экране шириной до 700 px. Пять ахроматических миниатюр первого кадра занимают 9 338 байт в WebP или 12 460 символов в представлении Base64 до сжатия таблицы стилей. При включённом уменьшении движения пользователь переходит по обычной ссылке и браузер пропускает загрузку внешних слоёв.

## Порядок композиции

| Проход | Файл | Движение |
| --- | --- | --- |
| Дальний план | `towers.webp` | Общий фотографический план включает небо, башни и площадку. Их положение стабильно. |
| Водяной пар | `steam.webp` | Светлая фактура извлечена из пара над устьями башен на соответствующей широкой или вертикальной композиции. Два экземпляра поднимаются от устьев с разной амплитудой. |
| Средний туман | `fog-mid.webp` | Боковая часть облака растушёвана по краям и проходит перед дальним планом. |
| Металлоконструкции среднего плана | `cranes.webp` | Светотеневая маска реальных контуров внутри арт-сцены возвращает фермы кранов поверх среднего тумана. Маска занимает те же координаты, что и базовый кадр. |
| Ближний план | `fog-front.webp`, `steam-bank.webp` | Самостоятельные гряды сходятся с разной скоростью. Ближние слои размыкаются над новой страницей. Плавное масштабирование общей архитектурной плоскости сохраняет совмещение ферм и башен при смене документа. |

Для смартфонов каталог `public/transition/compact/` содержит вертикальные площадку и маску кранов и уменьшенные атмосферные фактуры. В общем CSS находятся миниатюры первого кадра и облачных масс для отрисовки в момент смены документов. Режим сокращённого движения использует обычную навигацию.

Сборку сцены и временные кривые задают [React-компонент](../../components/IndustrialCloudTransition.tsx) и [таблица стилей](../../app/industrial-clouds.css).
