# Карта и состояние сайта ROIN WORLD

Проверка 22–23 ноября 2026 года. До редактирования сверены HTML-файлы опубликованной версии `c86989c`, динамические параметры Next.js, источники карточек и служебные маршруты. После правок карта сопоставлена с новым статическим экспортом, XML Sitemap, внутренними ссылками и фактическими открытиями в браузере. На всех пяти языках доступны те же 33 адреса. В каталоге три объекта, четыре направления, три публикации, семь вакансий и один индивидуальный профиль.

## Служебные адреса

| Адрес в корне публикации | Результат |
| --- | --- |
| `/` | Вход в статическую публикацию. HTML открывает русскую главную. В версии Node действует HTTP-перенаправление. |
| `/images/credits.html?lang=ru`, `en`, `ar`, `es`, `hu` | Пять языковых состояний самостоятельной страницы фотокредитов. Проверены заголовок, язык документа, RTL, источники и адаптивность. Страница исключена из индексации. |
| `/admin/` | Русскоязычный служебный вход. Проверены открытие и сообщение о режиме подключения. Доступ к редакторской учётной записи не предоставлялся. |
| `/404.html`, `/404/`, `/_not-found/` | Один экспортированный экран ошибки и два служебных представления Next. При обращении непосредственно к файлу статический сервер возвращает 200. |
| `/{язык}/qa-missing-page/` | В RU, EN, AR, ES и HU неизвестный адрес возвращает 404. Заголовок и переход на главную соответствуют языку адреса. |
| `/sitemap.xml`, `/robots.txt` | В карте 165 канонических адресов и альтернативы языков. robots указывает на карту и ограничивает индексацию служебных путей. |
| `/api/contact` | Серверный обработчик POST. На GitHub Pages обработчика нет. Статическая форма готовит письмо для почтовой программы посетителя. |
| `/documents/*.png` | Три исходных скана сертификатов. Проверены открытие, скачивание и соответствие оригиналу. |

Фильтры проектов, вакансий и новостей изменяют параметры запроса. Якоря открывают нужный раздел документа. Эти состояния остаются внутри указанных страниц. Отдельные технические файлы, шрифты, JavaScript, изображения и варианты их размеров не являются страницами.

В экспортированных HTML проверено 11 939 ссылочных вхождений в локальные страницы, якоря, изображения, сценарии и стили. Карта адресов совпадает с XML Sitemap. Подробности проверок и ограничения приведены в [итоговом отчёте](FULL_SITE_QA_REPORT.md).
