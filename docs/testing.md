# Проверка пользовательских сценариев

Тесты запускаются против уже работающего экземпляра приложения с исходным демонстрационным контентом и отключённым приёмом обращений. Для воспроизведения откройте два терминала в каталоге проекта.

В первом терминале установите зависимости и запустите production-сборку.

```sh
npm ci
npm run build
npm start
```

Во втором терминале установите Chromium для Playwright и запустите тесты.

```sh
npx playwright install chromium
npm run e2e
```

По умолчанию используется `http://localhost:3000`. Адрес можно задать через `TEST_BASE_URL`. Чтобы использовать уже установленный Edge, задайте полный путь к исполняемому файлу. Пример для PowerShell:

```powershell
$env:PLAYWRIGHT_CHROMIUM_EXECUTABLE = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
$env:TEST_BASE_URL = 'http://localhost:3000'
npm run e2e
```

Каталог для трассировок и скриншотов ошибок задаёт переменная `PLAYWRIGHT_OUTPUT_DIR`. По умолчанию Playwright пишет их в `roin-world-playwright` внутри системного временного каталога.

## Покрытие

| Сценарий | Наблюдаемый результат |
| --- | --- |
| Первый экран и избранные проекты | Карусели работают независимо, допускают переход через границу списка и открывают выбранный проект. |
| Каталог | Два фильтра применяются совместно. Для пустого результата доступен сброс. |
| География | Выбор метки синхронизируется со списком стран и ссылкой на проект. |
| Мобильное меню | Escape закрывает диалог и возвращает фокус. Из меню открывается каталог. |
| Локализация | Переключение RU → EN → AR сохраняет открытый проект, меняет язык документа и направление текста. |
| Фильм | Плеер создаётся после клика. Закрытие удаляет iframe и возвращает фокус. Внешний провайдер изолирован, воспроизведение самого фильма проверяется отдельно. |
| Закрытый приём обращений | Пустые поля не проходят проверку. Заполненная форма сообщает, как передать обращение по почте. Персональные данные остаются в браузере. |
| Адаптивность | На главной RU, EN и AR ширина документа проверяется при 360, 390, 768, 1024, 1440 и 1920 px. Длинные заголовки страницы конфиденциальности и новости проверяются отдельно при 360 и 390 px. |
| Ошибки браузера | Все сценарии отслеживают необработанные исключения и сообщения уровня error в консоли. |
| Доступность | Axe проверяет правила WCAG A и AA на трёх версиях главной и на русских страницах каталога, проекта, карты, новостей и контактов. |

Автоматические проверки охватывают Chromium. Для приёмки с реальными пользователями потребуются проверка скринридером, просмотр в Safari на iPhone и проверка воспроизведения корпоративного фильма из целевых регионов.
