# Материалы и план выпуска

## Оценка оставшейся работы

Это ориентир для планирования после передачи прототипа. Один человеко-день означает примерно восемь часов работы специалиста. Оценка предполагает три проекта, четыре направления и одну волну согласования. Срок ожидания согласий, переводы с нуля, съёмки, поездки и лицензии поставщиков оцениваются отдельно.

### STANDARD

| Этап | Результат этапа | Трудоёмкость |
| --- | --- | --- |
| Контент и дизайн | Утверждение фирменного знака, фактов, контактных данных и фотографий, вычитка трёх локалей | 3–6 чел.-дн. |
| Проекты и люди | Три согласованных кейса, руководство, документы, вакансии, субтитры предоставленного фильма | 3–7 чел.-дн. |
| Инфраструктура | HTTPS, корпоративный доступ в CMS, сборка после публикации, постоянный каталог обращений, резервное копирование | 2–4 чел.-дн. |
| Приёмка | Ревью специалистами компании, телефоны и браузеры заказчика, доступность, измерения на домене, обучение редактора | 2–4 чел.-дн. |

Ориентир STANDARD — **10–21 чел.-дн.** при своевременном предоставлении материалов.

### PREMIUM

Эти работы расширяют согласованный STANDARD. Каждый элемент можно выпускать самостоятельно.

| Этап | Дополнение | Трудоёмкость сверх STANDARD |
| --- | --- | --- |
| Кинематографические истории | Монтаж и адаптивная доставка видео, выбранные обложки, экономия трафика и субтитры | 3–7 чел.-дн. |
| Глубокие кейсы | Две-три истории с таймлапсами, инженерными этапами и интервью; дополнительные сценарии прокрутки | 4–9 чел.-дн. |
| Подробная карта | Раскрываемые площадки и слои по направлениям с подтверждёнными координатами | 2–5 чел.-дн. |
| Ещё две локали | Подключение подготовленных ES/HU, геометрия текста и регрессионное тестирование | 2–4 чел.-дн. |

Ориентир дополнительной разработки PREMIUM — **11–25 чел.-дн.** Сложность монтажа, количество объектов, число циклов согласования и система обработки обращений сильнее всего влияют на бюджет. Для экономии стоит начать с одного полностью согласованного кейса, повторно использовать утверждённый словарь и выпускать видео по мере готовности. Денежная оценка рассчитывается по ставкам команды и согласованному объёму.
