# ROIN WORLD MONUMENTAL 3.0

Редакция от 22 ноября 2026 года. Существующий проект Next.js развёртывается на GitHub Pages. Главная открывается документальной панорамой «Руппура». Следом идут интерактивная география, избранные проекты, факты, направления, партнёры и карьера. В продолжении страницы доступны команда, реестр сертификатов и форма связи.

## Визуальная сверка

В браузере Edge открыты страницы сайта на настольном и мобильном экранах. Снимки первого экрана, атласа, проектов и направлений сопоставлены рядом с двумя предоставленными макетами. В приложении к выпуску эти сравнения поставляются в PNG вместе с отдельными снимками всех блоков. Архив внешних референсов включает страницы SpaceX, Bechtel, Bouygues Construction, Webuild, Arup и AECOM. [Исследование и снимки международных сайтов](DESIGN_RESEARCH.md)

## Данные и публикация

Все пять языков доступны посетителю. Арабская версия использует RTL. Тексты и медиа редактируются через Decap. Все языковые версии имеют редакционный статус draft до согласования компанией. На GitHub Pages форма проверяет поля и готовит письмо, которое посетитель отправляет в почтовой программе. На сервере поддерживается приём через API. Для сохранения правок из публичной CMS необходим настроенный вход GitHub OAuth. [Инструкция редактора](cms.md) · [Режимы формы](contact.md)

Имя, должность и биография основателя приведены по публичному корпоративному источнику. Для размещения портрета и дополнительных персональных историй нужны согласованные компанией материалы. Изображение «Пакша» показывает действующую станцию, это обозначено в подписи. [Источники компании](sources.md) · [Реестр медиа](media.md)
